# Dart Intro — From Zero

A fresh, self-contained introduction to the Dart language. Each file is a
standalone lesson with its own `main()` you can run directly:

```bash
dart run dart_intro/01_hello_world.dart
```

| # | Lesson | Topics |
|---|--------|--------|
| 01 | `01_hello_world.dart` | `main()`, `print`, comments |
| 02 | `02_variables_and_types.dart` | `var`, `int`, `double`, `num`, `bool`, `String`, `dynamic`, `Object`, parsing & conversion |
| 03 | `03_strings.dart` | quotes, multi-line, raw strings, interpolation, string methods, `StringBuffer` |
| 04 | `04_operators.dart` | arithmetic, `~/`, assignment, comparison, logical, ternary, `??`, `?.`, `is` / `as`, cascade `..` |
| 05 | `05_control_flow.dart` | `if` / `else`, `switch` statement, `switch` expression, `assert` |
| 06 | `06_loops.dart` | `for`, `for-in`, `forEach`, `while`, `do-while`, `break`, `continue`, labels |
| 07 | `07_functions.dart` | return types, arrow syntax, optional & named parameters, higher-order functions, closures, recursion, `typedef` |
| 08 | `08_collections.dart` | `List`, `Set`, `Map`, `map` / `where` / `reduce` / `fold`, spread, collection-if / for |
| 09 | `09_null_safety.dart` | `?`, `!`, `?.`, `??`, `??=`, type promotion, `late` |
| 10 | `10_classes.dart` | fields, constructors (named, factory, const), getters / setters, `static`, operator overloading |
| 11 | `11_inheritance_abstract_interfaces.dart` | `extends`, `super`, `abstract`, `implements`, polymorphism, class modifiers |
| 12 | `12_mixins_and_extensions.dart` | `mixin`, `with`, `on`, extension methods |
| 13 | `13_enums.dart` | simple & enhanced enums, `values`, `byName` |
| 14 | `14_generics.dart` | generic classes, type bounds, generic functions |
| 15 | `15_exceptions.dart` | `try` / `catch` / `on` / `finally`, `throw`, `rethrow`, custom exceptions |
| 16 | `16_async_await_streams.dart` | `Future`, `async` / `await`, `Future.wait`, `Stream`, `async*`, `sync*` |
| 17 | `17_records_and_patterns.dart` | records, destructuring, pattern matching, `sealed` classes |
| 18 | `18_mini_project.dart` | a small grade-manager app combining everything |
